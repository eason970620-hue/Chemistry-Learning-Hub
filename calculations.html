化學計算公式

整理常見化學公式，讓複雜的計算變得更容易理解。

一、莫耳數計算

利用質量與莫耳質量計算物質的莫耳數。

公式

n = m / M

  • n：莫耳數（mol）
  • m：物質質量（g）
  • M：莫耳質量（g/mol）

範例

若有 18 g 的水，水的莫耳質量約為 18 g/mol：

n = 18 / 18 = 1 mol

二、莫耳濃度

表示每公升溶液中含有多少莫耳的溶質。

公式

C = n / V

  • C：莫耳濃度（mol/L）
  • n：溶質莫耳數（mol）
  • V：溶液體積（L）

範例

將 0.5 mol 的 NaCl 配製成 2 L 溶液：

C = 0.5 / 2 = 0.25 mol/L

三、溶液稀釋

稀釋時，溶質的莫耳數保持不變。

公式

C₁V₁ = C₂V₂

  • C₁：稀釋前濃度
  • V₁：稀釋前體積
  • C₂：稀釋後濃度
  • V₂：稀釋後體積

注意：兩側體積必須使用相同單位。
