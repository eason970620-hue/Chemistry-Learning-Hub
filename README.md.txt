
# ⚗️ Chemistry Learning Hub 化學知識庫

## 📖 專案介紹

Chemistry Learning Hub 是一個以化學學習為主題的知識網站，透過簡單清楚的分類，幫助學生理解化學觀念、認識實驗器材，以及整理常用計算公式。

本網站使用 HTML、CSS 和 JavaScript 製作，採用藍白色系的設計，提供簡潔且容易瀏覽的學習環境。

## 🎯 專案目標

- 整理常見化學知識。
- 學習化學實驗的基本觀念與安全守則。
- 整理常用化學計算公式。
- 建立個人化的化學學習筆記。
- 練習使用 HTML、CSS 和 JavaScript 製作網站。

## 📚 網站內容

| 頁面 | 內容 |
|---|---|
| 首頁 | 網站介紹與功能分類 |
| 化學知識 | 莫耳與莫耳濃度 |
| 實驗知識 | 實驗室安全、常見器材、實驗紀錄 |
| 化學計算 | 莫耳數、莫耳濃度、溶液稀釋公式 |
| 學習筆記 | 酸鹼、氧化還原與常見觀念 |

## 🛠️ 使用技術

- HTML：建立網頁結構
- CSS：設計網頁外觀與排版
- JavaScript：增加網頁互動功能
- GitHub：管理與分享專案
- GitHub Pages：發布網站

## 🤖 AI 協作規範

本專案使用 AGENTS.md 作為 AI 協作規範，明確定義網站的設計風格、檔案結構、程式碼撰寫方式與內容規則。

當 AI 協助新增頁面或修改功能時，可以依照這份規範維持網站的一致性，並降低修改時破壞既有功能的風險。
